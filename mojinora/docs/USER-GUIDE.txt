Mojinora 1.0.0 利用案内

対応環境
Windows 11 / x64。Node.jsなどの開発環境は不要です。
インストーラーには実行に必要なファイルが含まれ、オフラインで導入できます。
現在のWindowsユーザー向けにインストールします。管理者権限は不要です。

インストール
1. インストーラーを起動し、表示言語と利用条件を確認します。
2. 配置先を選択します。
3. デスクトップのショートカットと「Mojinoraで開く」の追加を選択します。
4. ファイル関連付けの画面で、分類ごとまたは拡張子ごとに対象を選びます。
5. 完了画面で必要に応じて「Windowsの既定アプリ設定を開く」を選択します。
   既定のアプリにしたい形式は、開いた設定画面で選んでください。
6. スタートメニューの「Mojinora」から起動します。

ファイルの右クリックと関連付け
「Mojinoraで開く」は拡張子のないファイルにも使えます。フォルダーには表示しません。
Windows 11では、右クリックの「その他のオプションを確認」内に表示されます。
複数の文書を選んで開けます。起動中なら既存ウィンドウのタブに追加し、同じファイルの未保存内容は保持します。
編集できない形式やフォルダーが含まれる場合は理由を表示し、他の文書を開きます。
関連付けは「プログラムから開く」と既定アプリの候補だけを登録します。現在の既定アプリを自動変更しません。
新規導入ではMarkdown（.md / .markdown / .mdown / .mkd）とテキスト・ログ（.txt / .text / .log）が選択済みです。
設定・データ、ソースコードも分類または個別で選べます。分類の一部だけ選ぶと中間状態で表示します。
任意拡張子はカンマ、セミコロン、空白で区切って入力し「追加」を押します。例: .abc; txt
先頭のピリオドと小文字表記を補い、重複を除きます。1つの拡張子はピリオドを除き1～63文字です。
パス、ワイルドカード、途中のピリオド、制御文字、既知の編集非対応形式は登録できません。
一覧が長すぎる場合はエラーを表示します。追加項目を減らして再試行してください。
右クリックと関連付けの選択は、次の上書きインストールで引き継ぎます。
選択解除は候補登録を除きますが、既定アプリの設定は書き換えません。変更したい場合はWindowsの設定で選び直してください。
アンインストールではMojinoraの登録だけを除き、他のアプリの登録や文書は変更しません。

サイレント導入（管理者権限不要）
Mojinora-Setup-1.0.0-x64.exe /S /currentuser /CONTEXTMENU=1 /EXTENSIONS=".md;.txt"
/CONTEXTMENU=0 または 1 で右クリック項目を切り替えます。
/ASSOCIATIONS=1 は .md / .markdown、0 は未選択を意味します。
/EXTENSIONS の明示指定を優先します。/EXTENSIONS="" は未選択です。無効な値では登録を変更せず終了します。
サイレント導入では既定アプリ設定画面を開きません。

表示言語
新規利用時はOSの最優先言語が日本語なら日本語、それ以外なら英語で表示します。
設定の「一般 → 表示言語」で「OSに合わせる」「日本語」「English」を選択できます。
「設定を保存」後にアプリを再起動すると反映されます。更新時は既存の言語設定を引き継ぎます。
文書の内容やファイル名は翻訳しません。

更新
作業中の文書を保存し、Mojinoraを終了して、新版のセットアップを実行します。
先にアンインストールする必要はありません。既存のインストール先を使用してください。
文書・画像・設定・自動復元データは引き継ぎます。自動更新機能はありません。

ネットワークドライブ上のファイル
通常の変更監視が使えない場合は、約1秒間隔の定期確認へ自動で切り替えます。
外部変更・削除・再作成を検出します。反映までの時間は通信状況によって変わります。
編集中の外部変更は確認を表示し、未保存の内容を自動で上書きしません。

基本操作
新規タブは通常テキストです。右下の「テキスト」からMarkdownの整形編集／ソース編集へ切り替えられます。
設定の「一般 → テキスト編集 → 新規文書の種類」で標準を変更できます。
ファイルを開くと、.md、.markdown、.mdown、.mkdはMarkdown、それ以外は通常テキストになります。
Ctrl+Sで保存、Ctrl+Zで元に戻します。ショートカットは設定画面で変更できます。
本文の標準フォントはConsolas、文字サイズは14pxです。設定から変更できます。更新時は保存済みのフォント設定を引き継ぎます。
編集領域でCtrl＋マウスホイール上／下を操作すると、本文の文字を拡大／縮小できます（50～200%）。倍率は起動中の全タブで共通になり、設定の文字サイズは変更しません。Ctrl+Shift+0（実際のサイズ）で100%に戻ります。次回起動時も100%から開始します。

終了と作業状態の復元
未保存の文書がある状態でアプリを終了すると、対象文書をまとめて確認します。
「すべて保存して終了」は各文書を保存します。名前のない文書には保存先を指定します。
「作業状態を保持して終了」は元ファイルを変更せず、開いていたタブと未保存内容を復元領域へ記録し、次回起動時に自動で開きます。
「変更を破棄して終了」は未保存の編集を残しません。「キャンセル」や保存の中止、記録の失敗では終了しません。
保持対象はタブ順・選択タブ、本文・Undo／Redo履歴（最大201時点）、文字コード・BOM・改行、選択・スクロール、編集モード・プレビュー、文書別Tab設定・構文言語、ブックマーク・折りたたみ、分割ペイン、サイドバーのフォルダーと展開状態です。管理画像も履歴分を含めて保持します。
大容量ログはファイル全体をコピーせず、位置・文字コード・追記監視を記録して開き直します。読み込めない場合はタブ内の「再試行」を使用できます。
「ファイル → 前回終了時の状態を復元…」で、最後の正常終了時の記録を手動で開けます。現在のタブを入れ替える確認と、未保存内容の保存確認があります。途中でキャンセルしても一部のタブだけを閉じません。
「作業状態を保持して終了」以外では、次回は空の文書で開始します。手動復元には保存済みの文書を記録し、破棄した無題文書や破棄した編集履歴は残しません。
復元記録は次の正常終了で更新します。自動復元は1回だけ行い、記録自体は手動復元用に残します。
元ファイルが外部で変更・削除されても、通常文書は記録した本文と履歴を優先します。通知を確認して外部版を読み込む、上書き、別名保存を選んでください。
検索結果・比較画面・ダイアログ・実行中のマクロや出力処理は復元しません。設定のエクスポートにも作業状態は含みません。

Markdownプレビュー
Markdown書式バーの目のアイコン「プレビュー」で、未保存の内容を読み取り専用表示します。
「編集に戻る」またはEscapeで、直前の整形編集／ソース編集に戻ります。選択・Undo履歴・編集位置を保持します。
閲覧位置はタブごとに保持し、タブを閉じるまで有効です。検索・置換やファイルタイプ変更では編集画面に戻ります。
文字の選択・コピー、リンク、目次・脚注の移動ができます。HTMLは実行せず原文表示します。
画像や数式を表示できない場合は理由を表示し、残りの本文は読めます。外部画像の許可設定も引き継ぎます。

設定のバックアップ
「設定 → バックアップ → エクスポート…」で、保存済みの全設定とショートカットをJSONへ出力します。
標準名はMojinora-settings.jsonです。設定画面で編集中の未保存内容は含みません。
「インポート…」は設定画面の下書きだけを置き換えます。「設定を保存」で反映し、キャンセルで破棄できます。
不正なファイル・未対応項目・不正値・ショートカット競合は理由を表示し、現在の設定と下書きを保持します。
文書、復元データ、保存済みマクロ、文書ごとの一時設定は含みません。表示言語の変更は再起動後に反映します。

通常テキストの編集
行番号をクリックすると、改行を含めてその行全体を選択します。最後の行に改行がなければ本文だけを選択します。
行番号を上下へドラッグすると複数行を選択します。折り返された行も元の1行として扱い、画面端の外へドラッグするとスクロールします。
Markdownのソース編集・コードブロック・分割ペイン・大容量ログ・ファイル比較でも同じ操作が使えます。
通常テキスト・左右分割・大容量ログの本文余白は上下左右3pxです。
右上の「元に戻す」「やり直す」は文書を操作します。検索欄にフォーカスがあっても対象は文書です。
プレビュー・大容量ログ表示中や履歴がない場合は無効です。
上部にはアイコン付きの編集機能・検索・置換・行へ移動・折り返し・画面分割・ファイル比較があります。
「編集機能」は1階層の一覧です。行移動・複製・削除、並べ替え・重複削除、インデント、コメント、折りたたみ、ブックマークを実行できます。
並べ替え・重複削除は選択中の論理行、未選択なら全文が対象です。次の行頭で選択を終えた場合、その次行は含みません。
並べ替えは数字を考慮した自然順です。重複削除は完全一致した行の最初の1行を残し、順序と文末改行を保持します。
空白記号のオン・オフは右下の「空白」から変更でき、再起動後も保持します。

選択文字列の変換
文字列を選び、「編集機能」から次の操作を選択します。未選択時は実行できません。
・小文字／大文字に変換
・全角→半角（ひらがなは維持）
・全角英数→半角英数／半角英数→全角英数（英字・数字のみ）
・全角カタカナ→半角カタカナ／半角カタカナ→全角カタカナ
・TAB→空白／空白→TAB
ひらがな関連の3操作は一覧から外しました。以前のカスタムキーと保存済みマクロは利用できます。
TAB・空白変換は文書のTab幅を使用し、選択前の行内位置も数えます。行中の連続半角スペースも、次のTab位置に届く部分をTABへ変換します。
変換できない文字や丸数字・漢字は保持します。複数選択・矩形選択は範囲ごとに変換し、変換後も選択を維持します。
行操作は重なる選択行をまとめ、離れた範囲をそれぞれ処理します。各変換はCtrl+Zで1回で戻せます。
変換キーは標準では未割り当てです。設定の「ショートカット」から登録できます。既存の独自設定は引き継ぎます。

構文の言語はファイル名から判定します。右下のファイルタイプを押して検索・変更できます。行番号の左側で折りたたみを操作します。
種類の切り替えではファイル名・本文・文字コード・Undo履歴を変更しません。手動指定はタブを閉じるまで保持します。
カーソルのある表示行の下端に薄い線を表示します。設定の「カーソル行に下線を表示」で無効にできます。
右下の「スペース: 4」などを押すと、現在の文書のTab入力と幅（1〜16）を変更できます。新しい文書は設定画面の既定値を使います。
Tabはタブ文字、または次のタブ位置までのスペースを挿入します。選択範囲がある場合は行のインデント、Shift+Tabはインデント解除です。
Altを押しながらドラッグすると矩形選択、Ctrl+Dで次の同じ文字列を選択に追加します。
Ctrl+F2で行のブックマークを切り替え、F4／Shift+F4で移動します。ブックマークはタブを閉じるまで保持します。
Ctrl+Gで行へ移動。折り返し、空白表示、フォント、タブ幅と空白インデントは設定で変更できます。
Ctrl+F／Ctrl+Hで検索／置換を開きます。正規表現、単語単位、選択範囲内を指定できます。
正規表現の置換には$1、$2、$<名前>などの参照を使用できます。検索が3秒を超えると中止します。
検索結果は10,000件までです。上限に達した場合は条件を絞ってください。

文字コードと改行
右下の文字コード表示から変更します。適用後の保存でファイルへ反映します。
UTF-8、UTF-16 LE／BE、CP932（Shift_JIS）、EUC-JP、ISO-2022-JPに対応します。
自動判定で文字化けする場合は、未保存の変更を保存してから「文字コードを指定して開き直す」を使用します。
選んだ文字コードで表せない文字がある場合、元ファイルは更新せずエラーを表示します。
LF／CRLF／CRを指定できます。既存ファイルの改行が混在する場合は、変更しない箇所の改行を保持します。

ファイルのドロップと製品情報
文書ファイルをサイドバー、タブバー、上部バー、本文、ステータスバーへドロップすると開きます。複数ファイルも扱えます。
Markdown本文への画像ドロップは画像挿入になります。画像と文書を一緒にドロップした場合は元の文書に画像を挿入してから文書を開きます。
フォルダーや編集できないファイルは理由を表示し、他の文書を開きます。
「ヘルプ → Mojinoraについて」でバージョンを確認できます。

GREP検索・GREP置換
Ctrl+Shift+FでGREP検索、Ctrl+Shift+HでGREP置換の条件画面を開きます。
対象フォルダーを入力するか「参照…」で指定します。サイドバーのフォルダーは変更しません。サブフォルダー検索は初期状態で有効です。
対象・除外パターンは「*.txt;*.log」「src/**/*.ts」のようにセミコロンで区切ります。
保存済みファイルのみを扱い、未保存のタブ、バイナリ、50MiB超のファイル、シンボリックリンク・ジャンクションを除外します。
検索後は下部の結果パネルを残したまま本文を編集できます。境界をドラッグすると高さを変更できます。条件の変更・再検索・中止・閉じるもここから行えます。
結果を押すと該当箇所へ移動します。検索後に変更されたファイルは再検索してください。
変更前と変更後を確認し、対象ファイルを選択して「選択したファイルを置換」を押します。
プレビュー後に外部で変更されたファイルや、新しく未保存になったタブは変更しません。
読み取り総量の制限はありません。結果は1,000ファイル／10,000件までで、上限到達・中止した結果からは置換できません。各ファイルの一致を最初は200件表示し、「さらに表示」で続きが見られます。
置換時は1ファイルずつ再計算し、文字コード・BOM・改行を保持します。変換不能文字や変更後50MiB超のファイルは書き込みません。
置換前のファイルを設定保存先のreplace-backupsへ保存します。結果にバックアップ先を表示します。
一括置換は文書のUndoでは戻せません。復元する場合は対象タブを閉じ、manifest.jsonのoriginalに記載された元の場所へ、対応する.bakファイルをコピーします。

分割と比較
通常テキストでCtrl+\を押すと同じ文書を左右に分割します。両側の編集は同じ文書とUndo履歴へ反映されます。
「ファイル比較」では別のタブと読み取り専用で比較します。比較対象は各10MiB以下です。

操作マクロ
通常テキストでF9を押して記録を開始し、入力・編集操作を行い、再度F9で終了します。F8で再生します。
ハンバーガーメニューの「マクロ → マクロを保存」「マクロ管理」から名前付き保存・再生・削除ができます。任意のスクリプトは実行しません。
文字入力、改行、文字の削除、矢印キーによる移動、行操作などを記録します。ファイル操作やマウスでの選択は記録しません。
再生は1回のUndoで戻せます。「再生を中止」またはEscapeで停止できます。
記録は10,000操作／1MiBまで、再生は最大100,000操作、保存したマクロは100件／合計8MiBまでです。

大容量ログ
50MiBを超えるファイルは読み取り専用で開きます。1GiBを超えるファイルも全体をメモリへ読み込みません。
先頭・末尾・前後のページと位置スライダーで移動します。行番号は表示中のページ内の番号です。
「追記を監視する」を有効にすると、約1秒ごとに末尾を再読み込みします。切り詰め・同じパスへの置き換えも追従します。
大容量ファイル自体は編集、文書内検索、フォルダー内検索・置換、比較、マクロの対象になりません。
改行のない非常に長い行は部分表示します。日本語の旧来文字コードでは境界確認のため前方のデータを読み取ることがあり、位置移動に時間がかかる場合があります。

Markdownの編集
文書の見た目を確認しながら操作する整形編集（WYSIWYG）と、Markdown記法を直接扱うソース編集を切り替えられます。
Ctrl+Sで保存、Ctrl+Zで元に戻す、Ctrl+1〜6で見出し、Ctrl+0で本文へ変更します。
Ctrl+Bは太字、Ctrl+Iは斜体、Shift+Enterは段落内改行です。
文字を選択すると、適用できる書式の小さなツールバーが表示されます。
ショートカットは設定画面で変更できます。

アンインストール
Windowsの「インストールされているアプリ」、またはインストール先の
「Uninstall Mojinora.exe」から削除します。
通常は設定と自動復元データを残します。「設定と自動復元データも削除」を
選ぶと、未保存の文書や一時画像を含む復元データも削除します。
保存済みの文書・画像は削除しません。必要な文書は先に保存してください。

通信とデータ
通常の文書編集・保存・自動復元は端末内で行います。
アプリに利用状況の収集やクラッシュレポートの自動送信機能はありません。
「外部URLの画像を読み込む」は初期状態で無効です。有効にすると、文書に記載された
画像の配信元へアクセスし、その配信元にIPアドレスなどの接続情報が伝わります。
外部リンクを開くと既定のブラウザーが開き、リンク先と通信します。
ダウンロードページ自体にはアクセス解析・外部フォント・問い合わせフォームを使用しません。
公開先のWebサーバーでは、その運営方針に従ってアクセスログ等が記録される場合があります。
