Mojinora 1.3.0 User Guide

System requirements and installation
Windows 11 / x64. No development tools, such as Node.js, are required.
The installer includes the required runtime files and works offline.
Installation is for the current Windows user and requires no administrator privileges.

1. Run the installer and select a language.
2. Review the terms of use and choose the installation folder.
3. Choose a desktop shortcut and the Open with Mojinora context-menu entry.
4. On File associations, select groups or individual extensions.
5. Optionally select Open Windows default-app settings on the final page.
   Choose the formats you want to open by default in the settings page.
6. Launch Mojinora from the Start menu.

File context menu and associations
Open with Mojinora works with files of any extension, including extensionless files, but not folders.
On Windows 11, it appears under Show more options in the file context menu.
New files open in the most recently used window. A file already open activates its existing window and tab, preserving unsaved edits.
Unsupported files and folders produce an explanation while other documents continue to open.
Associations register Open with and default-app candidates only. Setup never changes current default apps.
Fresh installations select Markdown (.md / .markdown / .mdown / .mkd) and text/logs (.txt / .text / .log).
Configuration/data and source-code groups are also available. Choose a whole group or individual extensions; partial groups show a mixed state.
Enter custom extensions separated by commas, semicolons or spaces and click Add, for example .abc; txt.
A leading dot is added, case is normalized and duplicates are removed. A suffix must be 1–63 characters excluding the dot.
Paths, wildcards, extra dots, control characters and known unsupported file types are rejected.
An excessively long list produces an error; reduce the number of custom extensions and retry.
Context-menu and extension choices are retained on the next in-place installation.
Deselecting an extension removes its candidate entry without changing the selected default app. Choose a different default in Windows Settings if needed.
Uninstalling removes only Mojinora registrations, leaving other apps and user documents unchanged.

Silent installation (no administrator privileges)
Mojinora-Setup-1.3.0-x64.exe /S /currentuser /CONTEXTMENU=1 /EXTENSIONS=".md;.txt"
/CONTEXTMENU=0 or 1 controls the context-menu entry.
/ASSOCIATIONS=1 selects only .md / .markdown; 0 selects none.
An explicit /EXTENSIONS list takes precedence. /EXTENSIONS="" selects none. Invalid values exit without changing registration.
Silent installation never opens default-app settings.

Language
For a new installation, the app uses the first preferred system language:
Japanese when it is Japanese, and English otherwise.
In Settings > General > Language, choose Use system setting, 日本語, or English.
Save settings and restart the app to apply a language change.
Existing language preferences are preserved when updating.
Your document content and file names are not translated.

Updates
Save your work, close Mojinora, and run the new installer.
Use the existing installation folder. Uninstalling first is not necessary.
Documents, images, settings, and recovery data are preserved. Updates are manual.

Files on network drives
When native change notifications are unavailable, the app automatically checks
for changes approximately once a second. External changes, deletion, and recreation
are detected; the response time depends on the connection.
If you have unsaved edits, external changes prompt a choice instead of overwriting your work.

Editing
New tabs use plain text. Click the file type at the bottom right to switch to Markdown (formatted) or Markdown (source).
Change the default under Settings > General > Text editing > Default document type.
Files ending in .md, .markdown, .mdown, or .mkd open as Markdown; other text files use text editing.
Ctrl+S saves and Ctrl+Z undoes. Keyboard shortcuts can be changed in Settings.

Tabs and windows
Right-click a tab to close other tabs, tabs to the left, tabs to the right, or all tabs. Close tabs to the left keeps the clicked tab and affects only its window. Cancelling an unsaved-document confirmation leaves all affected tabs open.
When tabs overflow, use the left/right buttons to scroll. Tab List searches all tabs in the current window by filename or path. Use Up/Down and Enter to select, and Escape to close the list.
Scroll up over a tab for the previous tab or down for the next; navigation wraps at both ends. Shift+wheel and horizontal gestures scroll the tab strip. Ctrl and other modifiers do not switch tabs.
Drag within the strip to reorder tabs. Release outside the window to move a tab to a new window, or use Move to New Window in its context menu.
Drop onto another window's tab strip to move to the indicated position. Drops on its editor area and Escape cancel the move.
Moves retain unsaved text, Undo/Redo, encoding, selection and viewing position without saving the original file. Moving the last tab closes its source window.
Settings are shared by all windows. Sidebar folders, split layout and search results belong to each window.

Organize tabs and use the command palette
Right-click a tab and choose Pin. Pinned tabs move to the left and are excluded from bulk-close commands. Pinned tabs cannot belong to a group.
Choose one of eight colors or No color for a tab. Use Move to Group to create a manual group and move a tab into it.
Rename, recolor, delete, collapse, or expand groups. New groups use blue by default; an individual tab color overrides its group's color. Collapsed tabs remain available in Tab List search; selecting one expands its group.
Pinned state, individual and group colors, and collapsed state are retained when tabs are reordered or moved between windows and when a work session is restored.
Press F1 or Ctrl+Alt+P to open the command palette. Search by command name, category, or shortcut in either Japanese or English. Unavailable commands are omitted. Use Up/Down and Enter to run a command, or Escape to close the palette.

Local save history
For documents with a save path, manual saves record the version before and after overwriting; a first save records the saved version. Automatic saves are excluded. Successful GREP replacements also record the before and after versions. Open Local History from the File menu or command palette to compare, restore, or delete versions.
A restored version is treated as unsaved and can be reverted with one Undo. Automatic saving stays paused until you save manually. History retains original bytes, encoding, BOM and line endings. Keeping the work session on exit also preserves the restored version.
History is retained for up to 30 days, 50 versions per file, and 500 MiB compressed in total. Older versions are removed when limits are reached. Turn off Record local save history in Settings to stop recording new versions; existing versions remain available for viewing, restoring, and deletion.
Use Delete all local save history in Settings to remove history for every document after confirmation. Work-session recovery data is stored separately and is not affected. History contents are not included in settings exports.

Exiting and restoring your session
The close button and Alt+F4 close only their window. File > Quit closes all windows; cancelling leaves every window open.
Keep session and exit on an individual window leaves a reservation for the next start. Reopening one of its files restores the retained content first.
When closing the app with unsaved documents, one dialog lists the affected documents.
Save all and exit saves each document, asking for a location for untitled documents.
Keep session and exit leaves the original files unchanged, records the open tabs and unsaved content in the recovery area, and restores them automatically at the next start.
Discard changes and exit does not retain unsaved edits. Cancel, a cancelled save, or a failed session write leaves the app open.
The session includes tab order and the active tab, text, Undo/Redo history (up to 201 states), encoding/BOM/line endings, selections and scrolling, editing/preview modes, document-specific indentation and syntax, bookmarks, folds, split panes, and the sidebar folder and expanded nodes. Managed images needed by the history are retained too.
Large logs are reopened at their recorded position, encoding and follow setting; the entire file is not copied. An unavailable log shows a Retry button in its tab.
File > Restore last closed session replaces all windows after confirmation. Unsaved documents also prompt you to save or discard. Cancelling midway leaves all tabs open. Window positions, sizes, maximized and full-screen states are also recorded.
Other exit choices start with an empty document next time. The manual checkpoint excludes discarded untitled documents and discarded edits and history.
The next normal exit replaces the checkpoint. Automatic restoration happens once; the checkpoint remains available for manual restoration.
For ordinary documents, recorded text and history take precedence over files changed or deleted externally. Review the notification before loading the external version, overwriting, or using Save As.
Search results, comparison views, dialogs, running macros and export operations are not restored. Settings export does not include the session.

Markdown preview
Select the eye icon, Preview, in the Markdown toolbar to read the unsaved document.
Back to editing or Escape restores the previous formatted/source editor, selection, Undo history and scroll position.
Preview state and reading position are kept per tab until it closes. Find, Replace and file-type changes return to editing.
Select and copy text, follow links, and navigate the table of contents and footnotes. Raw HTML is shown as text, never executed.
Unavailable images or formulas display an explanation while the rest of the document remains readable. Remote image permissions still apply.

Settings backup
Settings > Backup > Export writes all saved preferences and shortcuts to JSON, named Mojinora-settings.json by default.
Unsaved changes in the settings dialog are not exported. Import loads a draft; Save Settings applies it and Cancel discards it.
Invalid files, unsupported fields, invalid values and shortcut conflicts leave both current settings and the draft unchanged.
Documents, recovery data, saved macros and temporary per-document preferences are excluded. Language changes take effect after restarting.

Text editing
Click a line number to select the whole line, including its newline. A final line without a newline selects only its text.
Drag up or down across line numbers to select multiple lines. Wrapped text counts as one logical line; dragging beyond the viewport scrolls the editor.
The same operations work in Markdown source, code blocks, split panes, large logs and file comparison.
Text editing, both split panes and the large log viewer use 3px margins on all sides.
Undo and Redo at the top right target the active document, even while the search input is focused.
They are disabled in preview, in the large log viewer, or when no relevant history exists.
The icon toolbar contains Editing tools, Find, Replace, Go to line, Line wrapping, Split editor and Compare files.
Editing tools is a flat menu for line operations, indenting, comments, folding and bookmarks.
Sorting and deduplication affect selected logical lines, or the whole document without a selection. A selection ending at the next line start excludes that line.
Sorting uses natural numeric order. Deduplication keeps the first exact match and preserves order and the final newline.
Toggle Whitespace at the bottom right; the preference is retained after restart.

Selected text conversions
Select text and choose an operation from Editing tools. Conversion is disabled without a selection.
- Lowercase / Uppercase
- Full-width to half-width (hiragana stays unchanged)
- Full-width letters/digits to half-width, or the reverse (letters and digits only)
- Full-width katakana to half-width, or the reverse
- Tabs to spaces / Spaces to tabs
The three hiragana-related operations have been removed from the menu. Existing custom shortcuts and saved macros still work.
Tab conversion uses the document tab size and the column before the selection. Mid-line space runs reaching a tab stop also convert to tabs; remaining spaces stay unchanged.
Unmapped characters, circled numbers and kanji are preserved. Multiple and rectangular selections convert independently and remain selected afterwards.
Line operations merge overlapping selected lines and process separate blocks independently. Each conversion is one Undo step.
Conversions have no new default shortcuts. Assign keys in Settings > Shortcuts; existing custom keys are preserved.

Syntax language is detected from the file name. Click the file type at the bottom right to search and change it. Fold code from the gutter.
Changing file type preserves the file name, content, encoding, and Undo history. Manual choices last until the tab is closed.
A thin line marks the current visual line. Disable it with Underline the current line in Settings.
Click Spaces: 4 (or the current value) at the bottom right to choose tabs/spaces and a width from 1 to 16 for the current document. New documents use the defaults in Settings.
Tab inserts a tab character or spaces to the next tab stop. With a selection it indents lines; Shift+Tab unindents.
Alt-drag creates a rectangular selection. Ctrl+D adds the next matching occurrence to the selection.
Ctrl+F2 toggles a bookmark; F4 / Shift+F4 moves between bookmarks. Bookmarks last until the tab is closed.
Ctrl+G goes to a line. Settings include wrapping, whitespace, font, tab size, and space indentation.
In Settings > General > Text editing, configure each typing aid separately: inherit indentation on new lines, adjust indentation while typing, auto-close brackets and quotes, skip existing closing characters, delete paired characters together, and surround selected text. All are on by default. These aids apply to plain text and Markdown source editing, not Markdown formatted editing.
The default body font is Consolas at 14px. You can change it in Settings. Updates preserve your saved font preferences.
Hold Ctrl and scroll up/down over the editor to increase/decrease text zoom (50–200%). Zoom is shared across tabs for the current run and does not change the saved font size. Ctrl+Shift+0 (Actual size) resets it to 100%. Each launch starts at 100%.
Ctrl+F / Ctrl+H opens search / replacement with regex, whole-word, and selection-only options.
Regex replacements support $1, $2, and $<name>. Searches stop after 3 seconds and show up to 10,000 results.
The toolbar also provides Format Document, Format XML Strictly, Validate Syntax, and Compact Document for supported JSON, JSONC, JSONL, XML, HTML, CSS, JavaScript, TypeScript, JSX, and TSX files. Compact is available for JSON and JSONL only. Operations run in the background, support cancellation, and can navigate to a syntax error location. The document size limit is 10 MiB.
Formatting and compaction are manual commands; saving does not format automatically. Normal XML formatting preserves text and mixed content, while strict formatting preserves whitespace inside elements. JSON Lines remain one record per line. Processing stops after 15 seconds.

Encoding and line endings
Click the encoding indicator at the bottom right. Apply, then save the document.
Supported encodings: UTF-8, UTF-16 LE/BE, CP932 (Shift_JIS), EUC-JP, ISO-2022-JP, and EBCDIC IBM 930/939/1390/1399/037/1047.
If automatic detection is incorrect, save unsaved changes first, then use Reopen with encoding.
Saving stops without changing the original file if characters cannot be represented in the selected encoding.
Choose LF, CRLF, or CR. Mixed line endings are preserved at unchanged locations unless explicitly converted.

EBCDIC files
Normal Open, Open with Mojinora in the file context menu, and file drops estimate EBCDIC encodings. IBM 939 is preferred when candidates are ambiguous; a notification identifies the estimate. Detection cannot identify every file correctly.
When a file has no line endings and appears to use fixed records, confirm its record format and length. The initial value of 80 bytes is a suggested input, not a detected record length. Choose Text with line endings to open a non-record file as one line. Cancel skips this file while continuing with other files in the batch.
If text looks incorrect, use the notification or bottom-right encoding indicator to reopen it with its source CCSID. File > Open with Encoding lets you choose it before opening. An explicit encoding is never changed by detection.
930/939/1390/1399 support Japanese text; 037/1047 support Latin text. Edit the decoded text normally; saving writes it back in the selected EBCDIC encoding.
Text with line endings supports LF, CRLF, CR, and NEL (EBCDIC NL), retaining the selected line-ending format when saved.
For fixed-length records, enter a record length of 1–65535 bytes. Each record becomes one editor line. Files whose size is not a multiple of the selected length are rejected.
Saving pads short lines with EBCDIC spaces. Double-byte characters and SO/SI count toward the byte length. An oversized line stops the save and reports its line number and byte count.
Editor line breaks separate records. Adding a final line break adds an empty record; no line-ending bytes are written to the fixed-record file.
Use the bottom-right encoding indicator to change or reopen the encoding and record length. External reloads and work-session restoration retain them.
Conversion tables are bundled; no Java installation or network connection is required. Binary numeric fields and variable records with RDW/BDW are not supported.
Files over 50 MiB, or fixed records whose expanded text would exceed the 50 MiB editing budget, use the large read-only viewer.

Whitespace and tab positions
Whitespace display includes faint outlines for full-width spaces as well as space and Tab markers. Markers do not change saved text.
Switching tabs retains each document's vertical and horizontal scroll positions, independently for both split panes.

File drops and product information
Drop one or more document files on the sidebar, tab bar, top bar, editor, or status bar to open them.
Dropping images into a Markdown editor inserts them. For mixed drops, images are inserted into the original document before other documents open.
Folders and unsupported files are reported without preventing other documents from opening.
Help > About Mojinora displays the installed version.

GREP search and replacement
Use Ctrl+Shift+F for GREP search or Ctrl+Shift+H for GREP replacement.
Conditions include the folder, search and replacement text, include/exclude patterns, search options, encoding and fixed-record settings. Save, update, load, or delete named conditions; the 20 most recent runs are also kept. They are shared across windows. Selecting a condition only fills the form and does not start a search. Clear recent history with Clear search history. Conditions and history are not included in settings exports.
Enter a folder path or use Browse. The sidebar folder is not changed. Subfolder search is enabled by default.
Current file folder selects the active document's parent folder. It is disabled for untitled documents.
To search or replace EBCDIC, select its encoding and record format. Oversized fixed-record replacements are rejected; backups retain the original bytes.
Separate include/exclude patterns with semicolons, for example *.txt;*.log or src/**/*.ts.
Only saved files are included. Unsaved tabs, binary files, files over 50 MiB, symbolic links, and junctions are excluded.
Results stay below the editor while you edit or switch tabs. Drag the panel edge to resize it; use its controls to edit conditions, search again, stop, or close.
Click a result to navigate to the match. Search again if the file has changed since the search.
Review Before and After, select files, and choose Replace selected files.
Files changed externally since preview, and tabs with new unsaved changes, are skipped.
There is no combined input size limit. Results are limited to 1,000 files / 10,000 matches. Cancelled or truncated results cannot be used for replacement. Initially 200 matches per file are displayed; Show more reveals the rest.
Replacement is recalculated one file at a time, preserving encoding, BOM, and line endings. Unrepresentable characters or output exceeding 50 MiB prevent that file from being written.
Original bytes are backed up in replace-backups under the settings folder. The result shows the backup location.
Folder replacement cannot be undone using document Undo. To restore, close the affected tabs and copy the corresponding .bak files to the original paths listed in manifest.json.

Split and compare
In text editing, Ctrl+\ splits the same document into two views sharing edits and Undo history.
Compare files can use another tab's current content, the current file's saved version, or a selected file as the source. The source is read-only and the current document remains editable. Each difference can be applied with one Undo; automatic saving is paused until a manual save. Navigate between differences, view the count, and use synchronized scrolling (on by default). The display can ignore trailing whitespace or all spaces and tabs; applying a difference still uses the original text. Encoding, BOM and line-ending differences are shown separately. Each document must be no larger than 10 MiB.

Recorded macros
Press F9 in text editing to start recording, perform typing and editing commands, and press F9 again to stop. F8 replays.
Save macro and Manage macros provide named storage, playback, and deletion. Arbitrary scripts are not supported.
Typing, newlines, character deletion, arrow-key movement, and line commands are recorded. File operations and mouse selections are not recorded.
Playback is one Undo step. Use Stop playback or Escape to stop.
Limits: 10,000 actions / 1 MiB per recording, 100,000 actions per playback, and 100 saved macros / 8 MiB total.

Large logs
Files over 50 MiB open read-only. Files over 1 GiB are loaded in sections instead of being held entirely in memory.
Navigate using First, Last, Previous/Next page, or the position slider. Line numbers are relative to the displayed page.
Follow appended content reloads the tail approximately every second, including truncation or replacement at the same path.
Large files are excluded from editing, document search, folder search/replacement, comparison, and macros.
Very long lines are shown in parts. Legacy Japanese encodings may require reading earlier bytes to determine character boundaries, making position changes slower.

Markdown editing
Switch between formatted editing (WYSIWYG) and direct Markdown source editing.
Ctrl+S saves, Ctrl+Z undoes, Ctrl+1–6 applies headings, and Ctrl+0 applies body text.
Ctrl+B applies bold, Ctrl+I applies italic, and Shift+Enter inserts a line break.
Selecting text displays a small toolbar with the applicable formatting commands.
Keyboard shortcuts can be changed in Settings.

Uninstalling
Use Installed apps in Windows Settings, or run Uninstall Mojinora.exe from the
installation folder. Settings and recovery data are kept by default.
Selecting “Also delete settings and recovery data (including unsaved documents
and temporary images)” removes recovery data too. Save needed documents first.
Saved documents and images are not deleted.

Network access and data
Normal document editing, saving, and recovery take place on your computer.
The app does not automatically send usage analytics or crash reports.
“Load images from remote URLs” is disabled by default. Enabling it connects to
the image hosts specified in your document and shares connection information,
such as your IP address, with those hosts.
Opening an external link launches your default browser and connects to its destination.
The download page uses no analytics, external fonts, contact forms, or cookies.
The hosting server may record access logs according to its operator's policy.
